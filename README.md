Bem-vindo ao **code-lessons**! Um currículo aberto e prático de desenvolvimento de software desenvolvido por engenheiros de software seniores especialmente para estudantes do ensino médio que **nunca tiveram contato com programação**.

Aqui, o estudante não passa semanas decorando teorias abstratas: **ele cria e publica um site moderno e bonito logo na primeira aula**, despertando a curiosidade imediata para entender como a internet realmente funciona.

---

## 💡 Filosofia Educacional

Nosso modelo baseia-se em 10 princípios fundamentais:

1. **Curiosidade antes da teoria:** Primeiro veja a mágica acontecer; depois entenda o truque.
2. **Resultados visuais imediatos:** Todo código escrito gera impacto visual direto na tela.
3. **Projetos reais:** Criamos páginas e aplicativos que os alunos têm orgulho de mostrar para amigos e familiares.
4. **IA como tutora, nunca muleta:** A IA no terminal guia o aluno com perguntas socráticas e pistas graduais, sem entregar respostas prontas.
5. **Progressão gradual:** Começamos com HTML e CSS puros e avançamos até React, APIs, Python e automação física.
6. **Estímulo à experimentação:** O código é um laboratório aberto para testes, cores malucas e ideias autorais.
7. **Erros são bem-vindos:** Quebrar o layout ou esquecer uma tag faz parte da rotina de qualquer desenvolvedor.
8. **Esforço valorizado:** O assistente nunca resolve desafios sem que o aluno tente primeiro.
9. **Linguagem natural e descontraída:** Comunicação com o tom de um mentor sênior próximo e amigável.
10. **Zero burocracia técnica:** Sem instalações pesadas, ferramentas complexas de build ou serviços pagos no início.

## 🗺️ Trilha de Aprendizado (Curriculum Roadmap)

| Lição | Título | Foco Principal | Projeto Construído |
| :---: | :--- | :--- | :--- |
| **01** | **Meu Primeiro Site** | HTML5 Semântico, CSS Moderno, Visual First | Site pessoal sobre paixões (Games, Música, etc.) |
| **02** | **CSS e Design** | Flexbox, Cores, Tipografia, Cards e Sombras | Galeria / Vitrine de Projetos Estilizada |
| **03** | **Site Responsivo** | Media Queries, Layout Mobile-First, Menus | Landing Page completa adaptável a celulares |
| **04** | **JavaScript Interativo** | DOM, Eventos, Cliques, Modo Escuro/Claro | Painel de controle interativo com animações |
| **05** | **App de Tarefas** | Arrays, Objetos, Event Listeners, LocalStorage | To-Do List moderna que salva tarefas no navegador |
| **06** | **Primeiro React** | Componentes, Estados (`useState`), Props | Catálogo interativo de cards com busca em tempo real |
| **07** | **IA e APIs** | Requisições HTTP, `fetch`, APIs Públicas de IA | Gerador de conteúdo inteligente conectado à web |
| **08** | **Python Divertido** | Lógica de programação, automação e mini-games | Jogo de adivinhação e chatbot simples de terminal |
| **09** | **Arduino & Mundo Real** | Entradas/Saídas digitais, Sensores e Atuadores | Semáforo inteligente ou termômetro visual |

## ⚡ Como Iniciar a Primeira Aula (3 Passos)

1. **Abra o repositório** no seu editor de código preferido (como o VS Code).
2. **Abra o terminal** onde o assistente de IA está configurado.
3. **Digite a frase mágica:**
   ```text
   Quero começar minha primeira aula
   ```
4. Siga as instruções do seu mentor e prepare-se para ver seu primeiro site no ar!
