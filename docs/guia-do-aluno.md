## 💡 Os 4 Mandamentos do Aluno Desenvolvedor

1. **Você não vai quebrar o computador:** Pode clicar, editar, apagar e testar sem medo. Código se conserta com `Ctrl+Z` (ou `Cmd+Z` no Mac).
2. **Errar é parte do trabalho:** Quando um código dá erro, não significa que você é ruim nisso; significa que o computador só não entendeu uma instrução boba (tipo uma vírgula esquecida). Até engenheiro sênior erra todo dia.
3. **Não copie e cole no automático:** Ler o que o código faz e experimentar trocar uma palavra ou cor é o segredo de quem aprende rápido.
4. **Pergunte sem vergonha:** Seu professor e seu mentor de IA estão aqui exatamente pra tirar dúvidas. Não existe pergunta boba.

---

## 🛠️ Suas Ferramentas de Trabalho

Para as nossas aulas, você só precisa de duas coisas abertas no seu computador:

1. **Seu Editor de Código (como o VS Code):** É onde você vai ver e escrever os arquivos de texto do seu projeto (`.html`, `.css`, etc.).
2. **Seu Navegador de Internet (Chrome, Edge, Safari, Firefox):** É onde a mágica acontece e você vê o seu site funcionando de verdade.

---

## 🤖 Como Conversar com seu Mentor de IA

No seu terminal ou painel do assistente no editor, você tem um **Engenheiro Sênior** dedicado a você o tempo todo.

### Como falar com ele?
Você não precisa falar como um robô. Pode falar como fala no WhatsApp ou Discord:

- *"Quero começar minha primeira aula"*
- *"Cara, o que essa linha 14 faz?"*
- *"Tentei mudar a cor do botão pra roxo, mas ficou branco. O que rolou?"*
- *"Me dá uma dica de como colocar uma sombra bonita nesse card?"*

### A regra de ouro com a IA:
Use a IA como um **copiloto de corrida**, não como alguém que vai dirigir o carro no seu lugar. Quando travar num desafio, peça uma **dica**, não a resposta pronta. Você vai ver como a sensação de resolver um problema sozinho é incrível!

## 🌐 Como Ver Seu Site no Navegador

Não precisa de internet, nem de servidor pago!
1. Abra a pasta `lessons/01-meu-primeiro-site/projeto/`.
2. Dê um duplo clique no arquivo `index.html`.
3. Pronto! Ele vai abrir uma aba no seu navegador padrão.
4. Sempre que você alterar e salvar o código no editor, volte no navegador e aperte `F5` (ou `Ctrl+R` / `Cmd+R`) para ver a mudança acontecer na hora!
