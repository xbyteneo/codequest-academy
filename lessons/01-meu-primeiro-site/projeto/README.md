# Projeto: Meu Primeiro Site 🌐

Este é o projeto base da **Lição 01**. Você vai transformá-lo para que ele fique com a sua cara!

## 🚀 Como Abrir e Testar

1. **No seu computador:**
   - Dê um duplo clique no arquivo `index.html`.
   - Ele vai abrir direto no seu navegador (Chrome, Edge, Safari, Firefox).
2. **Se estiver no VS Code com a extensão Live Server:**
   - Clique com o botão direito no `index.html` e escolha **"Open with Live Server"**.

## 🎯 Seus 3 Primeiros Desafios (no arquivo `index.html`)

Procure no código os comentários com o símbolo 🎯:
- **Desafio 1 (Linha 37):** Mude o texto dentro de `<h1>` para o título do seu tema.
- **Desafio 2 (Linha 40):** Mude o texto dentro de `<p class="hero-subtitulo">` para a sua apresentação.
- **Desafio 3 (Linha 47):** Mude o texto do botão principal.

## 🎨 Próximos Desafios (no arquivo `style.css`)

- Vá até a linha 8 do `style.css` e experimente trocar os códigos de cores em `:root`!
- Salve o arquivo e recarregue a página no navegador (`F5`) para ver a transformação acontecer.
