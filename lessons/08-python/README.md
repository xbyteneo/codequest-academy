# Lição 08: Python Divertido — Lógica, Jogos e Automação 🐍🎮

> **Status:** 📋 Planejamento pedagógico. O projeto desta lição será implementado após a conclusão da Lição 07.

Depois de dominar as páginas da web, é hora de conhecer a linguagem mais querida da ciência de dados e da Inteligência Artificial no mundo: **Python**! Conhecida por sua sintaxe limpa que parece quase inglês puro, ela é perfeita para aprender lógica pura, criar scripts automatizados e jogos de terminal.

---

## 🎯 Objetivos de Aprendizado

- Entender a sintaxe elegante e a indentação obrigatória do Python.
- Dominar tipos de dados: inteiros, floats, strings e booleanos.
- Usar entrada e saída de dados no terminal com `print()` e `input()`.
- Criar estruturas de repetição (`while` e `for`) e condições (`if/elif/else`).
- Importar e utilizar módulos da biblioteca padrão, como `random` e `time`.

---

## 📋 Pré-requisitos

- Noções gerais de variáveis e lógica adquiridas nas lições anteriores de JavaScript.
- Python 3 instalado na máquina.

---

## 💻 Projeto Prático (Planejado)

**Terminal RPG: Jogo de Adivinhação e Batalha por Turnos:**
Um jogo executado diretamente no terminal onde o jogador enfrenta monstros virtuais, adivinha números secretos, ganha itens e faz escolhas de caminhos com base no seu raciocínio.

---

## 🧗 Desafios Progressivos Planejados

1. **Nível 1 (Primeiro Contato):** Criar um script `jogo.py` que pergunta o nome do jogador e dá boas-vindas personalizadas.
2. **Nível 2 (Adivinhe o Número):** O computador sorteia um número entre 1 e 50 com `random.randint()` e o jogador tem 5 chances de acertar, recebendo dicas de *"maior"* ou *"menor"*.
3. **Nível 3 (Placar e Vidas):** Adicionar um sistema de vidas e pontuação que diminui a cada erro.
4. **Boss Fight:** Criar um minissistema de batalha onde o jogador escolhe entre *"Atacar"*, *"Curar"* ou *"Fugir"*, com dano sorteado em cada rodada.

---

## ✅ Critérios de Conclusão

- [ ] Execução com sucesso do script `.py` através do comando `python3`.
- [ ] Uso correto de laços de repetição (`while`) para manter o jogo ativo.
- [ ] Manipulação limpa de entradas do usuário com `input()`.
- [ ] Atualização do arquivo `progresso.json`.

---

## 💡 Dicas para o Aluno

- No Python, o espaçamento no começo da linha (indentação) importa muito! Se você der 4 espaços, o Python sabe que aquele código está dentro do `if` ou do `while`.

---

## 👨‍🏫 Orientações para o Professor

- Destaque a diferença visual entre JavaScript (com suas chaves `{}`) e Python (com seus dois-pontos `:` e indentação). Isso ajuda a desmistificar a multiplicidade de linguagens de programação.
